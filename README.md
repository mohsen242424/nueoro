## ✨ Features

- **3D Anatomy Library** – Interactive Sketchfab 3D models for anatomical study
- **AI Assistant** – Smart chat for medical sciences questions
- **NEURO Courses** – Free educational courses with video lessons
- **GPA Calculator** – Semester & cumulative GPA with visual indicators
- **Doctors Directory** – Searchable faculty contact information
- **University Map** – Interactive campus navigation
- **Committees** – Learn about NEURO's 7 committees
- **Join NEURO** – Application form for new members
- **Dark Mode** – Full dark/light theme support

## 🛠️ Tech Stack

- **Next.js 14** (App Router, TypeScript)
- **TailwindCSS** (Custom design system)
- **Framer Motion** (Animations)
- **Sketchfab API** (3D model embedding)
- **React Three Fiber** (3D rendering)

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 📁 Project Structure

```
src/
├── app/          # Next.js pages (11 routes)
├── components/   # Reusable UI components
├── data/         # JSON data files
└── styles/       # Global CSS
```
